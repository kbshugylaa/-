# 📚 Сапалық және сандық есептер

> Физиканы жаттау емес — түсіну! ⚡

Интерактивті білім беру платформасы, оқушыларға физика пәні бойынша
сапалық және сандық есептерді түсінуге, шешуге және өз білімін тексеруге көмектеседі.

## 🎯 Жоба туралы

**«Сапалық және сандық есептер»** — физика есептерін шешу процесін
қарапайым әрі түсінікті етуге арналған цифрлық білім беру платформасы.

Платформа оқушыға дайын жауапты ғана көрсетпейді. Ол есептің шартын
талдауға, қажетті формуланы таңдауға және шешу алгоритмін түсінуге көмектеседі.

---

## 💡 Жобаның мақсаты

Жобаның негізгі мақсаты — оқушылардың физика пәніне қызығушылығын арттыру
және есептерді өздігінен шешу дағдыларын дамыту.

Платформа келесі қиындықтарды шешуге бағытталған:

- есептің шартын түсіну;
- қажетті формуланы таңдау;
- физикалық шамаларды анықтау;
- шешу алгоритмін құру;
- алынған жауапты тексеру.

---

## 🚀 Негізгі мүмкіндіктер

### 📖 Сапалық есептер

Физикалық құбылыстарды түсінуге арналған теориялық және логикалық тапсырмалар.

### 🧮 Сандық есептер

Формулалар арқылы физикалық шамаларды есептеуге арналған практикалық есептер.

### 💡 Қадамдық шешу жолы

Әр есепті шешу алгоритмі бірнеше түсінікті қадамға бөлінеді.

### 📐 Формулалар жинағы

Есептерді орындау кезінде қажетті негізгі физикалық формулалар көрсетіледі.

### 📝 Тест тапсырмалары

Оқушы өз білімін интерактивті тест арқылы тексере алады.

### 📊 Нәтижені бағалау

Тапсырмалар аяқталғаннан кейін нәтиже көрсетіліп, қателерді талдауға мүмкіндік беріледі.

## 🚀 Жобаны іске қосу

### Репозиторийді жүктеу

```bash
git clone https://github.com/kbshugylaa/- .git
cd -
```

### Іске қосу

Егер жоба статикалық HTML/CSS/JavaScript жобасы болса, `index.html` файлын
браузерде ашыңыз.

Жақсырақ нұсқа — жергілікті сервер қолдану:

```bash
python -m http.server 8000
```

Содан кейін браузерде мына мекенжайды ашыңыз:

```text
http://localhost:8000
```
